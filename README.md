# AICO — маршруты исследования

Интерактивная памятка преподавателя о маршруте исследования AICO, контрольных точках и методике измерений.

Статические страницы без сборщика и внешних сервисов:

- `index.html` — памятка преподавателя.
- `students/index.html` — главная для студентов: интерактивная фраза с управлением в первом экране, демонстрация четырёх форматов AICO (лонгрид / тест / кейс / чат), трёх уровней объяснения для лонгрида и чата, интересов для лонгрида (Minecraft, «Дюна», The Sims); тесты и кейсы не настраиваются, правила, участие и помощь в одной колонке.
- `students/route.html` — маршрут исследования: список шести этапов и описание выбранного; переключение без автоскролла, единая подача, отметки условных этапов. Переключатели находятся над описанием, примечание — под списком этапов.

Общая навигация «Главная → Правила → Маршрут» и её активное состояние — `students/site-ui.js`. Общие стили, две ширины контейнеров (1120 px для интерактивных блоков и 760 px для чтения) и встроенный Onest — `students/student.css`; поведение главной — `students/student-ui.js`, интерактивные примеры — `students/product-demo.js`, маршрута — `students/route.js`. Типографическая сцена — `students/letter-scene.js`, шрифты — `students/fonts/`. Начальный шрифт — YS Display Light. Наведение перебирает шрифты и сохраняет последний; курсор работает как лупа. Смену шрифта сопровождает небольшой прыжок. Волны оставляют новую композицию, пять нажатий на фразу включают пятисекундный ритм. Есть сброс, управление с клавиатуры и режим без движения. Лицензии — `students/OFL-Onest.txt` и `students/font-licenses/`.

Студенческая версия: https://tikhonov-cmd.github.io/aico-teacher-map/students/

Маршрут показывает события исследования, а не личный прогресс. Ссылки на формы, даты и контакты координатора нужно добавлять только после подтверждения для конкретного курса. Сейчас страница отсылает к приглашению и инструкциям команды курса; она не собирает данные участников.

## Публикация

Проект публикуется через GitHub Pages из корня ветки `main`. После изменения `index.html`:

```bash
git add index.html
git commit -m "Update site"
git push
```

Демонстрация посвящена причинности и A/B-тестам: скидки, самоотбор и сравнение изменений в двух группах. Данные и тематические сюжеты учебные. Тест содержит два фиксированных вопроса и не зависит от выбранной сложности. Динамическая часть выделена серым фоном. Методический ориентир: [Impact Evaluation in Practice, World Bank](https://www.worldbank.org/en/programs/sief-trust-fund/publication/impact-evaluation-in-practice).
