# AICO — маршруты исследования

Интерактивная памятка преподавателя о маршруте исследования AICO, контрольных точках и методике измерений.

Статические страницы без сборщика и внешних сервисов:

- `index.html` — памятка преподавателя.
- `students/index.html` — главная для студентов: интерактивная фраза с управлением в первом экране, персонализация объяснений (сразу суть / по шагам / на примере), правила, участие и помощь в одной колонке.
- `students/route.html` — отдельная страница с шестью этапами, подробностями исследования и ссылкой на методику преподавательской версии. Старые ссылки `students/#stage-t2` и аналогичные перенаправляются на эту страницу. Выбранный способ объяснения передаётся через `?mode=brief|steps|example`.

Общие стили и встроенный Onest — `students/student.css`; поведение главной — `students/student-ui.js`, маршрута — `students/route.js`. Типографическая сцена — `students/letter-scene.js`, шрифты — `students/fonts/`. Начальный шрифт — YS Display Light. Наведение перебирает шрифты и сохраняет последний; курсор работает как лупа. Смену шрифта сопровождает небольшой прыжок. Волны оставляют новую композицию, пять нажатий на фразу включают пятисекундный ритм. Есть сброс, управление с клавиатуры и режим без движения. Лицензии — `students/OFL-Onest.txt` и `students/font-licenses/`.

Студенческая версия: https://tikhonov-cmd.github.io/aico-teacher-map/students/

Маршрут показывает события исследования, а не личный прогресс. Ссылки на формы, даты и контакты координатора нужно добавлять только после подтверждения для конкретного курса. Сейчас страница отсылает к приглашению и инструкциям команды курса; она не собирает данные участников.

## Публикация

Проект публикуется через GitHub Pages из корня ветки `main`. После изменения `index.html`:

```bash
git add index.html
git commit -m "Update site"
git push
```
