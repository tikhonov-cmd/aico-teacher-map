# AICO — маршруты исследования

Интерактивная памятка преподавателя о маршруте исследования AICO, контрольных точках и методике измерений.

Две статические страницы без сборщика и внешних сервисов:

- `index.html` — памятка преподавателя.
- `students/index.html` — студенческая страница с персонализацией объяснений (сразу суть / по шагам / на примере), центральным первым экраном и морфингом пяти гарнитур у отдельных букв и волнами по нажатию, шестью этапами и прямыми ссылками на них. Пять нажатий на фразу включают пятисекундную быструю волну. Есть управление с клавиатуры и режим без движения. Типографическая сцена — `students/letter-scene.js`; шрифты заголовка — `students/fonts/`, основной текст использует встроенный Onest. Лицензии — `students/OFL-Onest.txt` и `students/font-licenses/`.

Студенческая версия: https://tikhonov-cmd.github.io/aico-teacher-map/students/

Маршрут показывает события исследования, а не личный прогресс. Ссылки на формы, даты и контакты координатора нужно добавлять только после подтверждения для конкретного курса. Сейчас страница отсылает к приглашению и инструкциям команды курса; она не собирает данные участников.

## Публикация

Проект публикуется через GitHub Pages из корня ветки `main`. После изменения `index.html`:

```bash
git add index.html
git commit -m "Update site"
git push
```
