# AICO — маршруты исследования

Интерактивная памятка преподавателя о маршруте исследования AICO, контрольных точках и методике измерений.

Статические страницы без сборщика и внешних сервисов:

- `index.html` — памятка преподавателя.
- `students/index.html` — главная для студентов: интерактивная фраза с управлением в первом экране, демонстрация четырёх форматов AICO (лонгрид / тест / кейс / чат), трёх уровней объяснения для лонгрида и чата, интересов для лонгрида (Minecraft, астрофото, 3D-печать); тесты и кейсы не настраиваются, правила, участие и помощь в одной колонке.
- `students/route.html` — маршрут исследования: список шести этапов и описание выбранного; переключение без автоскролла, единая подача, отметки условных этапов. Список этапов выровнен по верхнему краю серой карточки; переключатели находятся внизу карточки, примечание — под ней.

- `students/method.html` — внутренняя страница «Метод и измерения»: шесть разделов из преподавательской версии, оглавление с подсветкой текущего раздела при прокрутке на десктопе и раскрывающиеся пояснения. Оформление — общие стили студенческого сайта и `students/method.css`.

Навигация на трёх студенческих страницах: «Главная → Маршрут → Метод», с плавным переходом. На главной — две полупрозрачные ссылки на маршрут и метод. `students/site-ui.js` рассчитывает постоянную высоту карточки маршрута при изменении ширины. Демонстрационный блок подстраивается под видимое содержимое; его колонки объединены общим контуром. Кейс ведёт через выбор метрики, расчёт долей и интерпретацию результата. Неверные ответы выделены оранжевым с пояснением. Общие стили, две ширины контейнеров (1120 px для интерактивных блоков и 760 px для чтения) и встроенный Onest — `students/student.css`; поведение главной — `students/student-ui.js`, интерактивные примеры — `students/product-demo.js`, маршрута — `students/route.js`. Типографическая сцена — `students/letter-scene.js`, шрифты — `students/fonts/`. Начальный шрифт — YS Display Light. Наведение перебирает шрифты и сохраняет последний; курсор работает как лупа. Смену шрифта сопровождает небольшой прыжок. Волны оставляют новую композицию, пять нажатий на фразу включают трёхсекундный ритм. Есть сброс, управление с клавиатуры и режим без движения. Лицензии — `students/OFL-Onest.txt` и `students/font-licenses/`.

Студенческая версия: https://tikhonov-cmd.github.io/aico-teacher-map/students/

Маршрут показывает события исследования, а не личный прогресс. Ссылки на формы, даты и контакты координатора нужно добавлять только после подтверждения для конкретного курса. Сейчас страница отсылает к приглашению и инструкциям команды курса; она не собирает данные участников.

## Публикация

Проект публикуется через GitHub Pages из корня ветки `main`. После изменения `index.html`:

```bash
git add index.html
git commit -m "Update site"
git push
```

Демонстрация посвящена причинности и A/B-тестам: квест на научном фестивале, честное распределение вариантов, сравнение долей и выбор показателя. Данные и тематические сюжеты учебные. Тест содержит три самостоятельных фиксированных вопроса и не зависит от выбранной сложности. Динамическая часть выделена серым фоном. Методический ориентир: [Impact Evaluation in Practice, World Bank](https://www.worldbank.org/en/programs/sief-trust-fund/publication/impact-evaluation-in-practice).
