Current hero typefaces: YS Display Light300, Yeseva One400, Playfair Display900, Unbounded900, Ruslan Display400.

YS Display Light was supplied from the user’s installed font. The WOFF subset preserves its original Commercial Type copyright and proprietary license metadata. See ys-display-light-license.txt.

The other active hero families come from https://github.com/google/fonts (ofl directories). Their WOFF subsets contain the headline characters; variable fonts are instantiated to the listed weight. Each retains its SIL Open Font License alongside this file.

Earlier unused font files and licenses are retained for repository history. Onest remains embedded for reading and interface text; its license is ../OFL-Onest.txt.

Expanded active palette: Caveat600, Lobster400, Old Standard TT400italic, Press Start2P400 and Rubik Mono One400. Restored from the earlier local project font subsets; corresponding OFL files are retained here. Ten active typefaces in total.
